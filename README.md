# EcclesiaControl
EcclesiaControl é um ERP robusto e modular projetado para a gestão eclesial completa, oferecendo suporte a uma arquitetura multifilial (sede e congregações). Desenvolvido com Java Spring Boot e Angular/React, ele otimiza as finanças independentes ou consolidadas, o acompanhamento de membros e os fluxos de trabalho dos ministérios.
